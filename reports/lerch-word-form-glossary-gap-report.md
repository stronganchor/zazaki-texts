## Limitations

- This report is token-form based. It does not merge inflected forms, alternate historical spellings, or dialectal variants into lemmas.
- TSV rows are morpheme rows, so token counts were deduplicated by `segment_id` + `token_index`; malformed duplicate token coordinates would affect counts.
- Glossary search was filename-based and data-file oriented. Embedded code that supports dictionary features in `dist/` was intentionally excluded because it is not glossary entry data.
- Existing `lemma` and `gloss` fields in the text rows are included only as samples to help seed entries; they are not treated as an authoritative repository glossary.
