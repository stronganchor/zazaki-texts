Action guide

Use this page to decide what should happen to text-attested forms. First check whether a form is already covered by Lerch's glossary under a different spelling, lemma, or parent entry; only add a new public headword when that merge path does not work.

likely_add_or_merge
No plausible existing glossary hit was detected. Add only after checking the scanned Lerch glossary row.
likely_merge_existing
A related glossary entry already exists. Treat this as a variant, inflected form, or child entry unless review proves it is separate.
merge_or_function_entry
Function words, pronouns, prefixes, suffixes, and grammar particles. Do not add these as simple lexical headwords.
review_against_existing
A broad related hit exists, but the match is not strong enough for automatic merge.
review_high_value / review_lower_priority
No clear decision yet; use the example sentence, variants, and source scan before deciding.
